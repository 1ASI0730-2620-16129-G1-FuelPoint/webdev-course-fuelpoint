# Fundamentos de Desarrollo Web: HTML y CSS

Curso de video de ~60 minutos para estudiantes de secundaria (12 a 17 años) sin experiencia en programación.
**No necesitas instalar nada:** solo un navegador web (Chrome, Firefox, Safari o Edge) y un editor en línea gratuito como [CodePen](https://codepen.io/pen/).

La planificación académica completa y los enlaces del curso se encuentran en [`course-plan.md`](course-plan.md).

## Cómo usar este repositorio

1. Abre la carpeta de la lección en `starter-files/`.
2. Abre un Pen nuevo en [CodePen](https://codepen.io/pen/) (no necesitas registrarte).
3. Copia el contenido de `index.html` en el panel **HTML** y el de `style.css` (si existe) en el panel **CSS**.
   En CodePen no hace falta la línea `<link rel="stylesheet" href="style.css">`: el panel CSS ya se conecta solo.
4. Sigue los comentarios `PASO` mientras ves el video.
5. Si te atascas, compara tu trabajo con la misma lección en `completed-examples/`.
