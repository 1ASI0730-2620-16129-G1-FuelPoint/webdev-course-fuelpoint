# webdev-course-fuelpoint

Repositorio del curso introductorio sobre fundamentos del desarrollo web con énfasis en HTML y CSS, dirigido a estudiantes de secundaria (12 a 17 años) sin experiencia previa en programación.

## Plan del curso

La secuencia completa de lecciones, enlaces de video y actividades prácticas se encuentra en [`course-plan.md`](course-plan.md).

## Configuración

No requiere descargar ni instalar programas. Todas las prácticas se ejecutan directamente desde un navegador web mediante editores en línea gratuitos:

- [CodePen](https://codepen.io)
- [JSFiddle](https://jsfiddle.net)
- [Replit](https://replit.com)

## Estructura del repositorio

- `course-plan.md`: Documento principal del plan de curso en formato Markdown.
- `starter-files/`: Archivos HTML y CSS iniciales organizados por lección.
- `completed-examples/`: Soluciones completas en HTML y CSS de cada lección.
- `scripts/`: Guiones en Markdown correspondientes a cada video del curso.

## Requisitos técnicos para estudiantes

- Navegador web actualizado (Google Chrome, Mozilla Firefox, Safari o Microsoft Edge).
- Sin descargas ni instalaciones locales.
